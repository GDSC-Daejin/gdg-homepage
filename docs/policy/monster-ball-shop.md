# 프렌들리숍 몬스터볼 운영 정책

## 1. 목적

꼬북봇 활동으로 적립한 포인트를 몬스터볼로 교환할 수 있게 해 포인트 사용처와 도감 포획 루프를 제공한다.

상점 구현 계획과 기술 세부사항은 [몬스터볼 상점 계획](../plans/monster-ball-shop.md)을 따른다.

## 2. 포인트 교환

포인트는 웹사이트 내부 프렌들리숍에서 몬스터볼로 교환한다.

| 상품 | 가격 | 할인 |
| --- | ---: | ---: |
| 몬스터볼 1개 | 25P | - |
| 몬스터볼 3개 | 70P | 약 7% |
| 몬스터볼 5개 | 110P | 12% |

기본 교환 비율은 25포인트당 몬스터볼 1개다.

## 3. 일일 구매 제한

- 회원별 하루 구매 한도는 몬스터볼 5개다.
- 상품 단위가 아니라 구매한 몬스터볼 수량을 합산한다.
- 상품을 섞어 구매해도 하루 총 5개를 초과할 수 없다.
- 5개 묶음은 하루 1회까지 구매할 수 있다.
- 구매 한도는 KST 기준 날짜로 계산한다.

## 4. 진화 기여도 보상

진화 시점의 기여도 순위에 따라 몬스터볼을 추가 지급한다.

| 순위 | 추가 몬스터볼 |
| ---: | ---: |
| 1등 | 10개 |
| 2등 | 5개 |
| 3등 | 3개 |

진화 기여도 보상은 포인트 교환이 아니므로 일일 구매 한도에 포함하지 않는다.

## 5. 운영 원칙

- 몬스터볼은 디지털 아이템이며 운영 재고를 두지 않는다.
- 교환한 몬스터볼은 기존 무료 일일 보충으로 소진되지 않는다.
- 구매 후 환불은 제공하지 않으며, 교환 전에 차감 포인트와 지급 수량을 확인한다.
- 고급 볼·쿠폰·선물·환전·회원 간 송금은 초기 정책에서 제공하지 않는다.

## 6. 조정 기준

초기 운영 후 사용자별 교환률과 주간 교환량을 확인해 교환 가격 또는 일일 한도를 조정할 수 있다.
