# 트레이너 마켓봇 기획 초안

> 상태: Implemented

## 목표

회원이 슬랙에서 포켓몬 세계관의 게임코너와 관동 증권거래소를 즐겨 **트레이너 포인트(TP)**를 얻고, 이를 도감의 몬스터볼로 교환한다. 현금, 현금성 보상, 회원 간 송금은 제공하지 않는다.

## 하나의 봇, 하나의 세계관

봇 이름은 **트레이너 마켓봇**으로 한다. 게임코너·관동 증권거래소·프렌들리숍은 별도 봇이 아니라 이 봇의 메뉴다. 한 Slack 앱, 한 봇 계정으로 제공한다.

| 사용자 맥락 | 봇 안의 장소 | 하는 일 |
| --- | --- | --- |
| 트레이너 카드 | 포켓기어 | TP 잔액·출석·장마감 응원 투자 결과 확인 |
| 운 시험 | 게임코너 | 홀짝으로 TP 획득 또는 차감 |
| 자산 운용 | 관동 증권거래소 | 오늘 응원할 포켓몬 기업 하나 선택 |
| 포획 준비 | 프렌들리숍 | TP로 몬스터볼 교환 |

## 기존 기능과의 연결

- 도감은 이미 `pokemon_ball_inventory`로 몬스터볼 수량을 관리하고, 슬랙 반응으로 포획한다.
- 현재 일일 보충은 보유량을 정확히 3개로 설정한다. 교환한 볼을 보존하려면 `max(현재 보유량, 3)`으로 보충해야 한다.
- 기존 `point_logs`는 서비스의 일반 포인트 및 상점과 연결돼 있다. 트레이너 포인트는 이 원장과 완전히 분리한 게임 전용 원장을 쓴다.

## MVP 사용자 흐름

1. 회원은 트레이너 등록으로 지갑을 처음 만들고, 시작 TP와 하루 한 번의 출석 TP를 받는다.
2. `/포켓몬 게임코너`에서 금액 버튼과 홀·짝 버튼을 차례로 눌러 즉시 결과를 받는다.
3. 장중에 관동 응원판에서 포켓몬 기업의 시가와 오늘의 뉴스를 본다.
4. 기업 이모지+이름 버튼을 누르고, 개인 장수 선택창에서 1~3장의 응원권(장당 100TP)을 고른다. 서로 다른 기업은 최대 세 개, 하루 총 한도는 5장이다.
5. `/포켓몬 상점`으로 프렌들리숍 교환판을 열고, 1개·2개·3개 버튼으로 TP를 차감해 도감 몬스터볼을 즉시 받는다.
6. 도감의 기존 볼 보유량 확인 기능으로 교환 결과를 확인한다.

## 실제 사용자 여정

**대상 사용자: 활동 중인 회원 민지.** 민지는 포켓몬 도감을 채우고 싶지만, 매일 정해진 시간에 오래 접속하진 않는다. 점심이나 저녁에 Slack을 확인할 때 1~3분 안에 보상·운·수집 중 하나를 경험하는 것이 목적이다.

| 단계 | 민지의 행동 | 트레이너 마켓봇의 응답 | 감정 / 이탈 방지 |
| --- | --- | --- | --- |
| 발견 | `#아무말대잔치`의 포켓몬 출현·친구의 볼 교환 이야기를 본다 | 고정 안내에 `트레이너 마켓봇에서 TP를 모아 추가 몬스터볼을 받아요`를 표시한다 | 관심. 규칙을 한 문장으로 설명한다 |
| 연결 | 서비스 가입과 Slack 이메일이 같으면 자동 연결된다 | 연결된 회원만 트레이너 등록을 시작할 수 있다 | 이메일이 다르면 운영 화면의 수동 연결이 필요하다 |
| 첫 등록 | `/포켓몬 시작` | `트레이너 카드가 발급됐어요! 시작 TP 500을 받았어요. 포켓기어 출석·게임코너·증권거래소·프렌들리숍을 이용해 보세요.` | 즉시 TP와 사용처를 함께 보여 준다 |
| 일일 습관 | `/포켓몬 출석` | `포켓기어가 오늘의 탐험을 기록했어요. +50TP · 현재 550TP` | 1초 보상. 하루 한 번이라는 제한도 함께 안내한다 |
| 운 시험 | `/포켓몬 게임코너` → `100TP` → `⚡ 홀` | 적중: `피카츄 주사위 5 · 홀! +80TP` / 실패: `피카츄 주사위 2 · 짝. -100TP` | 두 번의 탭으로 결과·오늘 남은 횟수·오늘 남은 베팅 한도를 본다 |
| 자산 운용 | 관동 응원판의 `🧪 실프 주식회사` 버튼 → `2장 · 200TP` 버튼 | `실프 주식회사 응원권 2장을 샀어요. -200TP · 오늘 22:00에 자동 정산돼요.`를 개인 메시지로 표시한다 | 종목 입력 없이 세 종목까지 고르고 장수만 정한다 |
| 포획 준비 | `/포켓몬 상점` → `2개 교환 · 400TP` 버튼 | `프렌들리숍 교환 완료: 몬스터볼 2개 / -400TP / 현재 3개 보유` | 장바구니 없이 수량 버튼 한 번으로 끝낸다 |
| 수집 | 야생 포켓몬 원글에 `:pokeball:` 반응을 단다 | 기존 도감봇이 포획 결과와 남은 볼을 알려 준다 | TP의 목적이 실제 포획 기회로 돌아온다 |
| 장마감 | 22:00의 관동 시황을 확인한다 | 당일 응원 투자 정산, 최고 상승 기업, 수익·손실 상위 트레이너를 보여 준다 | 같은 날 결과를 받아 다음 참여로 이어진다 |

### 민지의 첫날 예시

```text
민지  → /포켓몬 시작
봇    → 트레이너 카드가 발급됐어요! 시작 TP 500을 받았어요.

민지  → /포켓몬 출석
봇    → 포켓기어가 오늘의 탐험을 기록했어요. +50TP · 현재 550TP

봇    → 📈 관동 응원판 · 장중 09:00~22:00
         [🧪 실프 주식회사] [🏭 몬스터볼 팩토리] [❤️ 포켓몬센터]
         [🏬 무지개백화점] [🔬 오박사연구소] [🚀 로켓단 홀딩스]

민지  → [🏭 몬스터볼 팩토리] 버튼을 누름
봇    → (민지에게만) 몬스터볼 팩토리 · 100TP
         오늘 0/5장 · [1장 · 100TP] [2장 · 200TP] [3장 · 300TP]

민지  → [2장 · 200TP] 버튼을 누름
봇    → (민지에게만) 몬스터볼 팩토리 응원권 2장을 샀어요. -200TP · 현재 350TP

민지  → [🧪 실프 주식회사] → [1장 · 100TP]
봇    → (민지에게만) 실프 주식회사 응원권 1장을 샀어요. -100TP · 총 3/5장 · 현재 250TP

민지  → /포켓몬 게임코너
봇    → (민지에게만) 게임코너 · 오늘 0/3회 · 현재 250TP
         오늘 남은 베팅 한도 100TP · [10TP] [50TP] [100TP]

민지  → [100TP] → [⚡ 홀]
봇    → (민지에게만) 피카츄 주사위: 5 · 홀!
         적중! 100TP를 걸어 180TP를 돌려받았어요. +80TP · 현재 330TP · 오늘 2회 남음 · 한도 0TP 남음
         [결과 공개]

민지  → /포켓몬 상점
봇    → (민지에게만) 프렌들리숍 · 현재 330TP · 몬스터볼 3개
         [1개 교환 · 200TP] [2개 교환 · 400TP] [3개 교환 · 600TP]

민지  → [1개 교환 · 200TP]
봇    → (민지에게만) 교환 완료! 몬스터볼 1개를 받았어요. -200TP · 현재 130TP
```

이후 민지는 도감 출현에 볼을 던진다. 자정의 무료 볼 보충은 보유 수량이 3개 미만일 때만 3개까지 채운다. TP로 교환한 볼은 사라지지 않는다.

### 항상 보이는 안전장치

- 잔액·출석·게임코너는 `/포켓몬` 명령으로, 주식 응원은 관동 응원판의 이모지+기업명 버튼으로 시작한다. 잔액과 기본 결과는 개인에게만 보인다.
- 게임코너는 `10·50·100TP` 금액 버튼을 누른 뒤 `⚡ 홀` 또는 `🔵 짝` 버튼으로 확정한다. 하루 3회·총 100TP를 넘길 수 없고, 결과 메시지의 `결과 공개` 버튼을 누른 경우에만 채널에 행동·결과 변화가 올라간다. 주식 응원은 개인 장수 선택으로 처리하고, 장마감 브리핑에서 결과를 함께 비교한다.
- 봇은 09:00 장시작에 `관동 아침 속보`, 22:00 장마감에 `관동 저녁 특보 + 장마감 브리핑`을 채널에 발송한다. 장마감 브리핑은 참가자별 당일 응원 투자 순이익 상위 3명과 순손실 상위 3명을 TP 변동·종목과 함께 공개한다. 총 TP 잔액은 공개하지 않는다.
- 장외(22:00~다음 날 09:00)에는 응원 투자를 받을 수 없다. 이미 고른 종목은 장마감까지 취소·교체할 수 없다.
- 응원판에서 기업 버튼을 눌러도 TP는 차감되지 않는다. 개인 장수 버튼을 누른 순간에만 장중 여부·동일 기업 중복·기업별 3장·하루 5장·TP 잔액을 다시 확인하고 확정한다.
- 게임코너에서 금액을 눌러도 TP는 차감되지 않는다. 홀·짝 버튼을 누른 순간에만 오늘 3회·총 100TP 한도와 TP 잔액을 확인하고 주사위 결과·차감·지급을 한 번에 확정한다.
- 프렌들리숍은 교환 수량 버튼을 누른 순간에만 TP 잔액을 확인하고 TP 차감·몬스터볼 지급을 한 번에 확정한다. 버튼 재전송으로 볼이 중복 지급되지 않는다.
- TP가 부족하면 거래·베팅·교환을 실행하지 않고 필요한 TP만 안내한다. 음수 TP·빚·송금은 없다.
- TP가 0이 되어도 다음 출석으로 50TP를 받아 다시 참여할 수 있다.
- Slack 계정이 연결되지 않았으면 회원 승인과 계정 연결이 필요하다고 알려 준다. 이메일이 다를 때는 Staff가 기존 연결 화면에서 한 번 처리한다.

**핵심 순간은 첫 프렌들리숍 교환 후 포획에 성공하는 때다.** 게임코너·증권거래소가 그 포획 경험으로 이어진다는 것을 여기서 체감한다.

### 장마감 브리핑 예시

```text
📰 관동 아침 속보 · 09:00
실프 주식회사가 포켓기어 신기능을 예고했어요. 오늘 관동 시장이 열렸습니다!

📣 관동 증권거래소 장마감
📰 관동 저녁 특보 · 22:00
포켓기어 신기능의 반응이 뜨거워 실프 주식회사가 강세로 마감했어요.

오늘의 급등: ROCKET +12% · 로켓단의 수상한 계획이 화제예요.

💰 오늘의 수익
1. <@민지> +15TP · ROCKET
2. <@준> +8TP · SILPH, BALL
3. <@하늘> +3TP · CENTER

📉 오늘의 손실
1. <@도윤> -8TP · OAK
2. <@소연> -5TP · CELADON
3. <@유나> -2TP · BALL
```

여러 종목을 고른 트레이너는 그날 자동 정산된 TP의 합계로 한 번만 순위를 매긴다. 순이익 또는 순손실이 0TP인 사람은 브리핑에서 제외한다.

## MVP 규칙

| 기능 | 확정 규칙 |
| --- | --- |
| 트레이너 포인트 | 전용 잔액. 현금 교환·송금·기존 포인트 상점 사용 불가 |
| 초기/일일 지급 | 최초 500TP, 하루 50TP. 수치는 운영 설정값 |
| 게임코너 홀짝 | 하루 최대 3회·총 100TP. 10·50·100TP 중 선택해 1~6 피카츄 주사위의 홀·짝을 맞히면 건 금액의 1.8배를 돌려받음 |
| 관동 증권거래소 | 아래 6개 고정 종목. KST 09:00 장시작, 22:00 장마감의 가상 가격을 사용하며 실제 종목·실시간 시세는 쓰지 않음 |
| 응원 투자 | 장중 서로 다른 기업을 최대 3개 고르고, 기업당 1~3장(장당 100TP), 하루 총 5장까지 선택. 장마감 가격 변동으로 자동 정산하며 매도·공매도·레버리지는 없음 |
| 프렌들리숍 | 몬스터볼 1개 200TP, 수량 제한 없음. 교환 후 즉시 도감 인벤토리에 반영 |

## TP 경제 — 첫 2주 파일럿

기존 도감의 무료 몬스터볼 3개는 매일 유지한다. TP는 그보다 더 포획하고 싶은 트레이너를 위한 추가 경로다.

| 항목 | 규칙 |
| --- | --- |
| 트레이너 등록 | 최초 500TP 지급 |
| 포켓기어 출석 | KST 하루 한 번 50TP 지급 |
| 게임코너 홀짝 | 하루 최대 3회·총 100TP. 10·50·100TP 중 선택, 홀·짝 적중 시 베팅액의 1.8배 지급 |
| 응원 투자 | 장중 서로 다른 기업을 최대 3개 고르고, 기업당 1~3장(장당 100TP), 하루 총 5장까지 선택. 당일 종가 변동과 장마감 응원 보너스로 자동 정산 |
| 프렌들리숍 | 몬스터볼 1개 200TP |

출석만 해도 4일마다 추가 몬스터볼 하나를 살 수 있다. 첫 지급 500TP는 처음 참여한 트레이너가 흐름을 바로 경험하도록 두 개의 몬스터볼 또는 주식 투자 자금으로 쓴다.

### 획득 폭 기준

| 경로 | 하루 기준 최대 변동 | 역할 |
| --- | ---: | --- |
| 포켓기어 출석 | +50TP | 꾸준히 모으는 기본 수입 |
| 게임코너 홀짝 | -100TP ~ +80TP | 즉시 결과가 나는 고위험·저보상 선택 |
| 관동 증권거래소 | 약 -11TP ~ +111TP | 장마감과 7일 추이를 기다리는 저위험·고보상 선택 |
| 프렌들리숍 | -200TP / 몬스터볼 1개 | 포인트의 명확한 사용처 |

주식의 최대 변동은 현재 변동폭에서 `ROCKET 3장 + OAK 2장`을 골랐을 때의 이론값이며, 장마감 응원 보너스 5장분(+50TP)을 포함한다. 홀짝은 더 빠르게 느껴지되, 하루 총 베팅 한도를 100TP로 묶어 주식·출석 보상을 한 번에 압도하지 못하게 한다.

### 일별 주가 규칙

| 기업 | 시작가 | 하루 변동폭 | 뉴스 예시 |
| --- | ---: | ---: | --- |
| 몬스터볼 팩토리 | 100TP | -3%~+3% | 신형 몬스터볼 생산 안정 |
| 포켓몬센터 | 130TP | -2%~+2% | 트레이너 무료 치료 지원 확대 |
| 실프 주식회사 | 150TP | -5%~+5% | 포켓기어 통신 기능 공개 |
| 무지개백화점 | 120TP | -5%~+5% | 프렌들리숍 기획전 성황 |
| 오박사연구소 | 200TP | -8%~+8% | 희귀 포켓몬 연구 발표 |
| 로켓단 홀딩스 | 80TP | -15%~+15% | 정체불명 투자 소문 확산 |

KST 09:00에 장을 열고 **전일 종가를 오늘 시가로 그대로 이어서** 관동 아침 속보와 함께 보여 준다. KST 22:00에 기업별 변동폭으로 종가·관동 저녁 특보를 확정하고, 당일 응원 투자를 그 변동률로 자동 정산한다. 가격은 10TP 아래로 내려가지 않는다.

응원권 한 장의 장마감 반환액은 `100TP + 해당 기업의 당일 가격 변동액 + 장마감 응원 보너스 10TP`다. 예를 들어 `CENTER`가 -2%여도 한 장은 108TP를, `ROCKET`이 +15%면 한 장은 125TP를 돌려준다. 기다린 시간 자체가 보상되되, 고변동 종목은 여전히 보너스보다 큰 손실을 낼 수 있다.

매일 기업별 시가·종가를 한 행으로 보존한다. 시장은 주말에도 매일 열리므로, `최근 7일`은 최근 7번의 장마감 기록을 뜻한다. 첫 장은 각 기업의 시작가를 시가와 종가로 시드한다.

### 기업 추이

`/포켓몬 추이 SILPH` 또는 `/포켓몬 시세`에서 최근 7일의 종가·등락률·추세를 보여 준다. 별도 차트 라이브러리 없이 Slack에서 읽기 쉬운 7칸 추이 막대를 쓴다.

```text
SILPH · 실프 주식회사
오늘 종가 168TP  ▲ 3.1%
7일 추이  ▂▃▃▄▆▅█
7일 등락  ▲ 12.0% · 상승세
```

7일 첫 종가와 마지막 종가를 비교해 `+2% 초과`면 상승세, `-2% 미만`이면 하락세, 그 사이는 보합으로 표기한다. 장마감 브리핑에는 그날 가장 크게 움직인 종목을, `/포켓몬 추이`에는 선택한 기업의 전체 7일 흐름을 보여 준다.

### 경제 가설과 확인

| 위험 | 가정 | 신뢰 | 첫 2주 확인 기준 |
| --- | --- | --- | --- |
| 가치 | 추가 몬스터볼이 게임 참여 동기가 된다 | 중간 | 활동 트레이너의 30% 이상이 한 번 이상 교환 |
| 사용성 | 게임코너·증권거래소·프렌들리숍 이름만으로 목적을 이해한다 | 중간 | 도움말 뒤 첫 명령 성공률 80% 이상 |
| 균형 | 출석 50TP·볼 200TP가 과도한 인플레이션을 막는다 | 낮음 | 주간 중앙 교환량 1~3개, 홀짝·주식의 일일 순손익 중앙값을 함께 확인 |
| 윤리 | 가상 TP·일일 베팅 한도·현금성 보상 차단이 과몰입 위험을 낮춘다 | 높음 | 홀짝 3회·100TP 한도 도달률과 운영 문의를 기록해 검토 |
| 운영 | 가상 가격과 한 줄 뉴스만으로 실제 시세 연동 없이 재미를 만든다 | 중간 | 주식 참여자 중 절반 이상이 3일 안에 다시 응원 투자 |

파일럿 종료 후 수치만 조정한다. 게임 종류, 실제 시세, 랭킹은 지표가 필요성을 보일 때만 추가한다.

## 명령 UX

- `도움말` · `내 TP` · `출석`
- `게임코너` → 금액 버튼 → `⚡ 홀` 또는 `🔵 짝`
- `상점` → `1개 / 2개 / 3개 교환` 버튼

게임코너는 `/포켓몬 게임코너`에서 개인 금액 버튼을 열고, 홀·짝 선택 뒤 즉시 주사위 결과를 표시한다. 주식은 09:00에 게시되는 관동 응원판에서만 고른다. 기업 버튼에는 항상 이모지와 기업명을 함께 표시하고, 누르면 본인에게만 장수 버튼이 열린다. 프렌들리숍은 `/포켓몬 상점`에서 개인 교환 수량 버튼을 연다. 개인 잔액·기본 결과는 본인에게만 보이고, 장마감 브리핑이 주식 결과를 채널에 공유한다.

## 최소 데이터와 안전장치

- `game_point_logs`: 모든 TP 지급·홀짝·응원 투자·교환을 남기는 변경 불가 원장
- `game_corner_bets`: 홀·짝 선택, 베팅액, 주사위 눈, 결과, 공개 여부
- `game_ball_redemptions`: 몬스터볼 교환 수량과 버튼 재전송 방지 기록
- `game_stock_symbols`, `game_stock_prices`, `game_stock_picks`: 종목, 날짜별 시가·종가·속보, 회원의 하루 응원 투자와 응원권 장수
- 모든 잔액 변경과 몬스터볼 교환은 하나의 DB RPC 트랜잭션에서 처리한다.
- 슬랙 사용자 ID와 기존 `profiles.slack_user_id`를 이용한다. 연결되지 않은 사용자는 게임을 시작할 수 없다.
- 베팅·응원 투자·교환에 최소/최대값과 충분 TP를 검증한다. 게임코너 결과·응원 투자·몬스터볼 교환은 각각의 기록과 고유 제약으로 중복 차감·중복 지급을 막는다.
- 관리자만 종목·가격 범위·보상·베팅 한도를 바꾼다.

## 비목표

- 실제 돈, 상품권, 기존 포인트, 외부 거래소 연동
- 실제 주가·실시간 시세·공매도·레버리지·주문 예약
- 여러 도박 게임, 회원 간 대결·송금, 랭킹·시즌제
- 몬스터볼 외 아이템과 고급 볼

## 구현 순서

1. 게임 전용 포인트 원장과 교환 RPC를 만든다. 기존 일일 몬스터볼 보충은 구매 수량을 지우지 않도록 수정한다.
2. 슬랙 앱 명령과 트레이너 등록·출석·게임코너 금액·홀짝 버튼·결과 공개를 연결한다.
3. 관동 응원판의 이모지+기업명 버튼·개인 장수 선택, 종목·시가·종가 이력·뉴스·7일 추이·응원 투자 자동 정산을 추가한다.
4. 프렌들리숍 개인 교환판·버튼 교환, 운영 설정, TP·거래 내역 조회를 추가한다.

## 확정 결정

- TP는 기존 서비스 포인트와 분리한다.
- 주식은 포켓몬 세계관의 기업으로 구성한 가상 일별 가격을 사용한다.
- 관동 증권거래소는 KST 09:00에 열고 22:00에 마감하며, 장중 서로 다른 기업을 최대 세 개까지, 기업당 1~3장·하루 총 5장의 응원권으로 투자할 수 있다.
- 첫 릴리스의 게임코너는 홀짝 하나만 제공한다.
