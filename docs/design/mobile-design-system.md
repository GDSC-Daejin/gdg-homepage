# 모바일 디자인 시스템

이 프로젝트의 모바일 반응형 판단 기준. 색·모션·재질 토큰은 `src/app/globals.css`(+ apple-design §섹션)에 있고, 이 문서는 **타이포 위계·터치·간격·레이아웃** 규칙을 다룬다. Tailwind v4 기본 스케일(4px 기반)에 매핑해 그대로 유틸로 쓸 수 있게 한다.

## 1. 타이포 스케일 (하한 있음)

| 역할 | Tailwind | px / line-height | 굵기·색 |
|---|---|---|---|
| **제목** | `text-xl`~`text-2xl` `leading-tight` | 20~24 / 1.25 | `font-bold` `text-gray-900` |
| **본문** | `text-sm`~`text-base` | 14~16 / 1.5 (기본) | `font-medium`/`font-normal` `text-gray-800`~`900` |
| **캡션** | `text-sm` | 14 / 1.5 | `text-gray-500` (연하게) |
| **보조 정보** | `text-xs` | 12 / 1.33 | `text-gray-400`~`500` |

**하한 규칙**
- 본문은 **최소 13px**, 일반적으로 14~16px → 본문에 `text-xs`(12) 금지. `text-sm` 이상.
- 어떤 텍스트도 **최소 12px** → `text-[11px]` 등 12 미만 금지. `text-xs`가 절대 하한.
- 줄 간격: 본문 1.4~1.6배(Tailwind 기본 `leading-normal`≈1.5가 이 범위), 제목처럼 짧고 굵은 텍스트는 1.2~1.4배(`leading-tight`/`leading-snug`).

## 2. 정보 위계 — 결정 요소 4가지

한 요소의 강조도는 아래 4가지의 **조합**으로 만든다. 크기 하나로만 위계를 만들지 않는다.

1. **폰트 크기** — 제목 > 본문 > 보조
2. **굵기** — `font-bold` > `font-medium` > `font-normal`
3. **색상** — `text-gray-900` > `800` > `500` > `400` (진할수록 강조)
4. **여백** — 강조 요소 주변에 공간을 더 준다

예: 캡션과 보조 정보는 크기가 같아도(둘 다 작게) **색**으로 위계를 가른다 — 캡션은 진하게, 보조 정보는 연하게.

## 3. 터치 · 대비

- **터치 영역 최소 32px** → 버튼/링크/아이콘 히트박스 `min-h-8 min-w-8`(32px) 이상. 아이콘이 작아도 히트박스로 확보. 실사용 권장은 44px(`h-11`)이나 하한은 32.
- 인접 탭 타깃 사이 **충분한 여백** 확보(밀집 금지).
- **명도 대비 4.5:1 이상** (본문 텍스트/배경). 연한 회색(`gray-400`)은 보조 정보·큰 텍스트에만.
- 버튼 상태별 피드백: `hover:`/`active:`/`disabled:`/`aria-*` 명시.

## 4. 여백 · 간격

- **관련 있는 요소는 가까이, 관련 없는 요소는 멀리** (proximity).
- **4·8 배수 간격 시스템** 사용 — Tailwind spacing(`gap-2`=8, `gap-3`=12, `gap-4`=16, `p-4`, `py-6`…)이 4px 기반이라 유틸을 쓰면 자동 준수. 임의값(`gap-[13px]`) 금지.

## 5. 레이아웃 원칙

- **1 페이지 = 1 메인 액션.** 화면당 primary 버튼(`bg-primary`)은 하나. 나머지는 secondary/ghost.
- **모바일 우선.** 기본 스타일 = 모바일, `sm:`(640px)부터 데스크톱 레이아웃으로 확장.
- 셸 사이드바(`w-60`)는 데스크톱 전용 — 모바일에선 숨기고 상단바 + 드로어로 대체.
- 데이터 테이블은 모바일에서 카드 리스트로 전환하거나 가로 스크롤 컨테이너(`overflow-x-auto`)로 감싼다.
- 컨텐츠 좌우 패딩: 모바일 `px-4`, 데스크톱 `sm:px-8`.

## 6. 브레이크포인트

Tailwind 기본. 이 프로젝트는 `sm`을 데스크톱/모바일 경계로 쓴다.

| 프리픽스 | 최소 너비 | 용도 |
|---|---|---|
| (기본) | 0 | 모바일 |
| `sm:` | 640px | 태블릿~데스크톱 (사이드바 노출, 다열 그리드) |
| `lg:` | 1024px | 넓은 데스크톱 (필요 시) |
