# 도감 발견 정보 노출 설계

## 목표

포켓몬을 포획하기 전에는 이미지와 상세 설명을 숨기고, 포획한 뒤에만 공개한다. 이 문서는 이전 확률표 설계의 이미지 공개 규칙을 대체한다.

## 표시 규칙

- `/pokedex?tab=probabilities`의 포켓몬별 확률표는 이름, 번호, 희귀도, 출현 가중치, 포획률을 항상 표시한다.
- 확률표에서 미획득 포켓몬 이미지는 회색 실루엣으로 표시한다. 포획한 포켓몬은 원본 이미지를 표시한다.
- `/pokedex/[pokedexNo]` 상세 페이지에서 미획득 포켓몬은 회색 실루엣과 `???` 설명을 표시한다. 포획한 포켓몬은 원본 이미지와 종별 설명을 표시한다.
- 내 도감의 기존 미획득 실루엣 및 이름 `???` 표시는 바꾸지 않는다.

## 데이터와 구현

- 목록 페이지가 이미 조회하는 본인 성공 포획 기록으로 포획 여부를 판별한다.
- 상세 페이지가 이미 조회하는 본인 성공 포획 기록으로 포획 여부를 판별한다.
- 새 API, 데이터베이스 변경, 공통 컴포넌트는 추가하지 않는다.

## 검증

- 확률표가 포획 여부에 따라 원본 이미지 또는 회색 실루엣을 렌더링하면서 이름은 항상 표시하는지 확인한다.
- 상세 페이지가 미획득일 때 회색 실루엣과 `???` 설명을, 포획했을 때 원본 이미지와 설명을 렌더링하는지 확인한다.
