# 도감 랭킹전 UI 리디자인 설계

## 목표

현재 도감 랭킹전의 데이터와 조작을 유지하면서, 제공된 게임 UI 레퍼런스처럼 시즌 요약과 랭킹을 먼저 읽을 수 있는 포켓몬 테마 화면으로 재배치한다.

## 범위

- 좌측(넓은 화면): 시즌, 내 점수, 전적, 일일 공격 횟수, 활성 방어 덱을 요약한다.
- 우측(넓은 화면): 시즌 랭킹을 순위 행 형태로 보여 준다.
- 아래: 공격·방어 프리셋, 오늘의 상대, 전투 기록은 기존 정보와 동작을 그대로 둔다. 오늘의 상대에는 선봉 포켓몬 한 마리만 공개한다.
- 좁은 화면에서는 요약, 랭킹, 기존 조작 영역 순으로 세로 배치한다.
- 전투 시작은 코인 선공 결정, 선공 안내, 몬스터볼 투척, 발광 이펙트와 포켓몬 등장 순으로 재생한다.

## 2차 범위 — 시안 대조 후 반영분

시안(`Ranking Battle Redesign.dc.html`의 4a·3a)과 현재 기획을 대조해 아래만 반영한다. 시안 전체는
`/ranking-preview`에서 볼 수 있고, 접은 항목은 그 화면의 `UNADOPTED` 목록에 이유와 함께 남긴다.

- 상태 RPC(`pokedex_rank_state`)에 네 값을 더한다. 규칙·점수·매칭은 그대로다.
  - `entry.rank` — 리더보드는 상위 20명만 오므로 그 밖의 회원은 자기 순위를 볼 방법이 없었다.
  - `leaderboard[].userId` — 이름 대신 id로 "나"를 식별한다.
  - `battles[].role` — 공격전인지 방어전인지 없어서 방어에 뚫린 것을 읽을 수 없었다.
  - `battles[].opponentNickname` — 상대 카드·리더보드와 표기를 맞춘다.
- 홈에 "오늘 할 일" 세 카드(남은 공격 / 방어 덱 상태 / 최근 24시간 방어 결과)를 둔다.
- 남은 공격을 칸으로 보여주고 다음 갱신(06:00)까지 남은 시간을 함께 적는다.
- 저장된 전투 기록의 점수 변동을 되짚어 시즌 점수 추이를 그린다. 별도 스냅샷 테이블은 만들지 않는다.
- 시즌 진행률과 함께 1~3위까지 남은 점수, 보상 조건(10전 이상·공격 5회 이상) 달성 여부를 보여준다.
- 전투 기록에 공격·방어 배지와 필터(전체/공격/방어), 점수 변동을 둔다.
- 프리셋 슬롯은 드롭다운 대신 1·2·3 버튼으로 고른다.
- 상대 방어 덱은 세 칸으로 그리되 선봉 한 칸만 공개하고 나머지 두 칸은 `미공개`로 둔다.

## 제외

- 레퍼런스의 재화, 리그 보상, 별도 등급, 게임 전용 장식은 만들지 않는다.
  **티어(브론즈·실버·골드·마스터)는 넣지 않는다.** 시즌은 1,000점에서 시작하는 점수제 하나만 쓴다.
- 상대 상성 판정과 조언, 상대 방어 승률, 타입 대비 추천 조합은 넣지 않는다. 공개하지 않기로 한
  나머지 두 마리의 정보가 새어나간다.
- 순위 변동(▲2)은 일별 순위 스냅샷이 없으므로 넣지 않는다.
- 포켓몬별 승률과 라이벌 상대전적은 팀 단위 승패를 개별에 배분하기 어려워 보류한다.
- 동아리 소식 피드(다른 회원의 전투 결과)는 공개 범위를 정한 뒤에 다시 본다.
- 랭킹전을 여러 페이지로 나누지 않는다. 도감 탭 안의 한 화면을 유지한다.
- API, 서버 액션, 랭킹 규칙, 전투 흐름, 테스트 셀렉터는 바꾸지 않는다.
- 새 이미지나 의존성은 추가하지 않는다.

## 표현 규칙

- 기존 디자인 시스템의 컴포넌트·색상·간격 토큰과 기존 포켓몬 이미지만 사용한다.
- 요약·랭킹 영역은 카드보다 밀도 있는 패널로 구분하고, 상위 순위는 포켓몬 테마의 색상 강조로만 구별한다.
- 랭킹 행에는 순위, 사용자명, 점수만 둔다. 파티 정보는 오늘의 상대 카드에 공개된 선봉 포켓몬 한 마리만 표시하며, 나머지 파티·보상 정보는 표시하지 않는다.
- 코인·선공 안내·초기 투척 중에는 전투 포켓몬 이미지를 렌더링하지 않아, 등장 이펙트가 처음 표시될 때 재생된다.

## 검증

- 랭킹전 참가 전/후 상태가 모두 정상 표시된다.
- 키보드로 기존 버튼과 선택 요소를 조작할 수 있다.
- `pnpm typecheck`와 랭킹전 관련 테스트를 실행한다.
