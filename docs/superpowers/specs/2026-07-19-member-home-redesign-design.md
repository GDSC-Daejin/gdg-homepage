# Member Home Redesign Design

## Goal

로그인한 GDG on Campus DJU 멤버가 공지와 다음 이벤트를 가장 먼저 읽고, 월간 포인트와 지난 이벤트를 한 화면에서 빠르게 확인하도록 홈 대시보드의 위계와 밀도를 개선한다.

## Scope and constraints

- 범위는 로그인 후 루트 경로(`/`)의 `HomeDashboard` 한 화면이다.
- 좌측 사이드바, 파란 브랜드색, 최신 공지, 다가오는 이벤트는 유지한다.
- 이벤트·공지·설문·포인트·지난 이벤트의 데이터 조회, 링크, URL 월 필터와 정보 구조는 변경하지 않는다.
- 기존 Tailwind 토큰과 `Card`, `Badge`, `EmptyState` 컴포넌트를 사용한다. 새 의존성·색상·폰트는 추가하지 않는다.
- 키보드로 도달 가능한 링크와 기존 빈 상태를 유지하고, 모바일에서는 데스크톱 2열을 한 열로 쌓는다.

| 영역 | 현재 계약 | 변경 여부 |
| --- | --- | --- |
| 전역 | `MemberShell`의 좌측 사이드바와 사용자 메뉴 | 변경하지 않음 |
| 페이지 이동 | 이벤트 카드 링크, 공지 링크, 설문 링크, 월 필터 URL | 변경하지 않음 |
| 핵심 정보 | 다가오는 이벤트와 참가 인원 | 상단의 넓은 핵심 패널로 격상 |

| 데이터 계약 | Supabase 조회와 `month` 검색 매개변수 | 변경하지 않음 |

## Chosen visual direction

선택한 시안은 이벤트 중심의 2열 레이아웃이다. 제목 아래의 공지·설문 스트립을 빠르게 훑은 뒤, 좌측의 다음 이벤트를 가장 크게 읽고 우측의 월간 포인트를 보조적으로 확인한다. 지난 이벤트는 낮은 대비의 별도 섹션으로 둔다.

- **위계:** 인사말과 다음 이벤트를 가장 크게, 공지·설문은 한 줄 스트립, 포인트와 지난 이벤트는 그 다음 순서로 배치한다.
- **표면:** 페이지 배경은 기존 `gray-50`; 이벤트와 포인트는 한 덩어리의 그리드 안에서 카드로 구분하고, 공지·설문은 얕은 보더의 스트립으로 만든다.
- **강조:** `primary`는 이벤트 유형, 이벤트 타이틀의 보조 요소, 포인트 수치에만 쓴다. 설문은 기존 warning tone을 유지한다.
- **밀도:** 이벤트는 메타데이터를 두 줄로 정리하고, 카드 간 간격을 줄인다. 지난 이벤트의 빈 상태는 기존 컴포넌트를 그대로 쓴다.
- **반응형:** `sm` 미만에서는 이벤트·포인트 그리드를 한 열로 전환한다. 사이드바의 모바일 드로어 동작은 그대로 둔다.

## Implementation shape

`HomeDashboard.tsx`만 수정한다. `EventCard`는 다음 이벤트와 지난 이벤트에서 같은 데이터를 표시하되, `featured` 여부로 크기와 메타데이터 계층만 다르게 렌더링한다. 공지와 설문은 기존 조건부 렌더링·링크를 유지하면서 일관된 스트립 스타일을 사용한다.

데이터 조회·정렬·필터링 코드는 건드리지 않는다. 시각 구조 변경으로 테스트 가능한 순수 로직은 추가되지 않으므로, 타입 검사와 홈 경로의 수동 링크·반응형 확인으로 검증한다.

## Design review

- 사용자 승인 시안의 필수 요소 네 가지(사이드바, 파란색, 공지, 다가오는 이벤트)를 모두 포함한다.
- 새 기능, API, 정보 구조, 의존성은 추가하지 않는다.
- `featured` 스타일은 한 파일에서만 사용하는 조건이므로 새 컴포넌트·타입을 만들지 않는다.
