# 일정 확정 알림·백업 플랜

## 목표

회의 조율을 확정하면 운영진이 놓치지 않도록 Jarvis가 Slack 운영진 채널에 확정 내용을 알리고, 확정 화면에서 확정안과 대체 후보를 명확히 구분한다.

## Slack

- `confirmMeetingPoll`이 DB 확정을 마친 뒤 Jarvis 토큰으로 `SLACK_ADMIN_CHANNEL_ID`에 한 번의 메시지를 보낸다.
- 메시지는 `<!channel>` 멘션, 일정 제목, 확정 일시, 소요 시간, 일정 링크를 포함한다.
- 메시지 끝에 `:cb3dc3d2-fd74-4a3b-a9e1-f7ad58497090:` 커스텀 이모지로 확인해 달라는 문구를 넣고, 발송한 메시지에 Jarvis가 같은 이모지 반응을 단다.
- Slack 메시지 또는 반응 실패는 DB 확정을 되돌리지 않는다. 기존 노션 실패와 동일하게 화면 경고로 반환한다.

## 확정 화면

- 확정 전에는 기존의 추천 시간 카드 3개를 유지한다.
- 확정 후에는 상단에 `확정된 일정` 카드로 날짜·시간·소요 시간을 보여 주고, 관리자는 같은 위치에서 확정을 취소할 수 있다.
- 그 아래 `백업 플랜`에는 확정 시간을 제외한 추천 후보를 최대 2개 보여 준다. 각 후보는 날짜·시간, 가능한 인원, 불가능한 인원을 유지한다.
- 추천 후보가 없으면 백업 플랜 전체를 표시하지 않는다.
- 기존 데이터 계약, 확정 권한, 추천 알고리즘, 모바일 단일 열 레이아웃은 유지한다.

## 검증

- 확정 성공 시 Slack 메시지·이모지 반응 호출과 실패 경고를 단위 테스트한다.
- 관련 일정 조율 테스트와 타입 검사를 실행한다.
