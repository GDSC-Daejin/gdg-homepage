# 도감 랭킹전 미리보기 설계

## 목표

관리자 포켓몬 개발 탭에서 실제 랭킹전 화면과 흐름을 안전하게 검토한다. 친선 결투 미리보기는 유지한다.

## 범위

- 개발 탭에 랭킹전 미리보기를 추가한다.
- 실제 `RankingLeaguePanel`을 재사용해 참가, 공격·방어 프리셋의 3마리 선택·저장, 방어 덱 활성화, 상대 리롤, 공격, 전투 기록 조회를 같은 UI로 제공한다.
- 미리보기 전용 포켓몬 여섯 마리, 랭킹, 상대와 전투 기록을 클라이언트 상태로 둔다.
- 미리보기 조작은 DB, 실제 시즌·랭킹·포획 기록, 서버 액션을 변경하지 않는다.

## 구현 경계

`RankingLeaguePanel`은 기본적으로 기존 서버 액션을 계속 사용한다. 미리보기에서만 상태 변경 함수를 주입해 로컬 fixture를 갱신한다. 별도의 랭킹전 UI를 복제하지 않아 실제 화면과 미리보기의 동작이 갈라지지 않는다.

## 검증

- 개발 탭에서 참전부터 전투 기록 상세 보기까지 완료할 수 있다.
- 미리보기에서 덱과 상대를 바꿔도 실제 랭킹전 데이터는 변경되지 않는다.
- 관련 테스트와 타입 검사를 통과한다.
