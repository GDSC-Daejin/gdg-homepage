# 모지숲 회의록 — 설계

## 배경

동아리 운영 주간회의 "모지숲"(주 1회~격주)의 회의록을 서비스에서 다룬다.
회의는 온라인(디코 음성 + 노션 서기)이 대부분, 가끔 오프라인(대면 + 노션 서기)으로
진행된다. **어느 쪽이든 서기는 항상 노션에서** 이뤄지므로, 온/오프라인은 설계를
가르지 않고 회의에 붙는 태그(방식) 하나일 뿐이다.

Staff는 이미 노션 유료 계정으로 회의·서기·Notion AI(녹음/전사/요약)를 노션에서
처리한다. 반면 **Member는 노션 시트가 없어 회의 결과를 볼 수 없다.** 이 기능이
존재하는 이유는 **노션 회의록을 Member가 (노션 없이) 요약으로 볼 수 있게 하는 것**이다.

## 큰 그림

> **노션 = 작업 공간(source of truth) · 사이트 = Member용 read-only 거울**

- Staff: 노션에서 회의·서기·Notion AI 녹음/요약. "사이트 공개" 체크한 회의만 대상.
- 사이트: 공개된 노션 회의를 Notion API로 끌어와 Member에게 요약으로 보여줌.
- **사이트는 회의록을 쓰지 않는다.** 오직 읽어서 보여준다.

원래 요청의 "지난안건 브리핑 + 이번주 안건 미리 세팅"과 "AI 녹음"은 둘 다
**노션이 기본 기능으로 더 잘한다.** 안건 이월은 노션 DB 템플릿 + relation으로,
녹음/전사/요약은 Notion AI로 해결한다. 우리가 코드로 만들 필요가 없다.

## 노션 쪽 (커넥터로 세팅)

**"모지숲 회의록" 데이터베이스** 속성:

| 속성 | 타입 | 용도 |
|---|---|---|
| 제목 | title | 회의명 |
| 일시 | date | 회의 날짜 |
| 방식 | select (온라인 / 오프라인) | 태그 |
| 사이트 공개 | checkbox | ✅ 켠 회의만 사이트로 나감 |
| 공개 요약 | text | **Member가 보는 요약.** 내부 얘기 제외하고 서기가 정리 |
| 지난 회의 | relation(self) | 브리핑 연결 |

**새 회의 템플릿**에 ①정기 안건 틀(예: 예산 / 이벤트 / 회원) ②이월 안건 자리
③지난 회의 relation을 박아둔다. 새 회의를 열 때마다 브리핑 + 이번주 안건이 자동
세팅된다. 녹음·전사·요약은 페이지 본문에서 Notion AI가 처리한다.

> 안건 이월 로직은 **노션 템플릿이 담당**한다. 사이트 코드로 구현하지 않는다.

## 사이트 쪽 (구현 대상)

기존 **Community Store seam** 위에 그대로 얹는다. 새 store 집합 하나 추가.

### 데이터 모델 — `meetings` 테이블 (Supabase)

공개된 노션 회의의 **거울(mirror)**. Notion API 접근은 동기화 한 곳에만 모으고,
Member 페이지 렌더는 이 테이블만 읽는다(매 렌더마다 노션 호출 없음).

| 컬럼 | 타입 | 비고 |
|---|---|---|
| `id` | uuid | 우리 PK |
| `notion_page_id` | text unique | upsert 키 |
| `title` | text | |
| `meeting_date` | date/timestamptz | 회의 일시 |
| `mode` | text | `online` \| `offline` |
| `summary` | text | 공개 요약(노션 "공개 요약" → 텍스트) |
| `notion_url` | text | 노션 페이지 링크 (Staff에게만 노출) |
| `synced_at` | timestamptz | 마지막 동기화 시각 |
| `created_at` | timestamptz | |

거울에는 `사이트 공개=✅`인 회의만 들어온다. 노션에서 공개를 끄면 다음 동기화 때
거울에서 제거(또는 숨김)한다.

### MeetingStore

- **reads**: 공개 회의 목록(일시 내림차순), 회의 상세.
- **ops**: `syncFromNotion` — 노션 공개 회의를 거울 테이블로 upsert, 공개 해제된
  건 정리.
- **Supabase adapter**: `meetings` 테이블 읽기 + 동기화 upsert.
- **Demo adapter**: 샘플 회의 반환(둘러보기 자동 지원). 동기화는 성공 형태 no-op.

### 동기화

- `/admin`에 **"노션에서 동기화" 버튼**(서버 액션). 누르면 `사이트 공개=✅` 회의를
  거울로 upsert.
- Notion API 토큰은 서버 환경변수. 동기화 액션은 **Staff만**.
- 지금은 **수동 동기화만.** (원하면 나중에 기존 attendance-warning cron 패턴처럼
  자동화 — 이번 범위 밖.)

### 화면 · 권한

- **Member 화면**: `/notices` 옆에 회의록 목록/상세. 일시 · 방식 · 공개 요약 표시.
  노션 링크는 시트 없는 Member에겐 무용하므로 **Staff에게만** 노출.
- **읽기 권한**: 로그인 Member 이상(목록·상세).
- **동기화 권한**: Staff만.

## 명시적으로 안 하는 것 (YAGNI)

- 사이트에서 회의록/안건 **작성·편집** ❌ (노션이 함)
- STT · 오디오 스토리지 · 요약 파이프라인 ❌ (Notion AI가 함)
- 안건 이월 자동화 코드 ❌ (노션 템플릿이 함)
- 실시간 라이브 노션 임베드 ❌ (요약 거울만)
- 자동/주기 동기화 ❌ (수동 버튼만, 자동화는 후속)

## 열린 항목

- 노션 "공개 요약" 리치텍스트를 사이트에 어떤 포맷으로 저장할지(플레인 텍스트 vs
  간단 마크다운) — 구현 시 노션 API 응답 형태 보고 결정.
- 공개 해제된 회의를 거울에서 하드 삭제할지 숨김 플래그로 둘지 — 구현 시 결정
  (기본: 하드 삭제로 단순하게).
