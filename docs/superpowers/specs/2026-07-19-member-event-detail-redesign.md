# 회원 행사 상세 리디자인

## 목표

선택 시안 B처럼 행사 정보를 빠르게 훑고 신청 상태를 분명하게 확인할 수 있게 `/events/[id]`의 배치만 개선한다.

## 유지

- 행사·신청·출석·관련 글의 데이터 조회와 URL, 서버 액션, 테스트 셀렉터
- `Card`, `Badge`, `EventLocation`, `NaverMap`, `RegistrationPanel`과 기존 색상 토큰
- 장소·주소·발표자·설명 값이 없을 때 해당 정보가 보이지 않는 동작

## 화면 규칙

- 헤더에는 제목과 행사 유형 배지를 함께 둔다.
- 넓은 화면은 좌측 정보 카드와 우측 지도 카드를 2열로 둔다. 모바일은 정보 카드 뒤에 지도를 한 열로 쌓는다.
- 정보 카드는 일시·장소·발표자를 가는 구분선으로 나눈다. 주소의 지도·복사 동작은 그대로 둔다.
- 신청 현황은 별도 전폭 카드에서 숫자와 정원 정보를 우선해 보여 준다. 진행률은 정원이 있을 때만 표시한다.
- 신청 상태 카드는 기존 상태 배지와 취소/신청 액션을 유지하며, 좁은 화면에서는 세로로 쌓는다.

## 범위 제외

- API·데이터 모델·카피·상태 정책 변경
- 새 아이콘·UI 라이브러리·공통 컴포넌트 추가
