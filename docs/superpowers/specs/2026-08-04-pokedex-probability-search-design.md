# 도감 확률표 포켓몬 검색

## 범위

- `/pokedex?tab=probabilities`의 확률표 위에 포켓몬 이름 검색 폼을 둔다.
- 제출하면 `q` 쿼리 문자열을 유지한 채 포켓몬별 확률표만 이름으로 필터링한다.
- 일치하는 포켓몬이 없으면 빈 결과를 안내한다.
- 랭킹전 오픈 예정 안내는 태블릿에서 한 열로 쌓고, 데스크톱부터 두 열로 표시한다.
- 안내 문구의 강제 줄바꿈을 제거하고, 제목의 행간·자간은 좁은 화면에서 읽기 좋게 둔다.

## 제외

- 입력 중 즉시 필터링, 별도 클라이언트 컴포넌트, 희귀도별 확률표 필터링은 추가하지 않는다.
- 색상·탭·정보 구조·데이터 흐름은 바꾸지 않는다.

## 검증

- 검색 폼과 현재 검색어가 렌더링된다.
- 일치하는 이름만 포켓몬별 확률표에 표시된다.
- 결과가 없을 때 안내가 표시된다.
- 태블릿보다 좁은 화면에서는 안내 카드가 한 열이고, 강제 줄바꿈이 없다.
