# 공지사항 아코디언

## 범위

회원 공지 목록(`/notices`)에서 공지 카드를 누르면 상세 페이지로 이동하던 동작을, 같은 카드 안에서 본문을 열고 닫는 동작으로 바꾼다.

## 구현

- 서버의 공지 조회, 발행 상태 필터, 최신순 정렬과 빈 상태는 유지한다.
- 각 공지에 네이티브 `details`/`summary`를 사용한다. 공지는 서로 독립적으로 열고 닫을 수 있다.
- 요약 영역은 제목·발행일·펼침 표시를 보이고, 펼친 영역은 기존 상세 페이지와 같은 본문과 줄바꿈을 표시한다.
- 키보드 조작과 펼침 상태 접근성은 HTML 기본 동작을 사용한다. 클라이언트 상태나 새 의존성은 추가하지 않는다.
- `/notices/[id]` 경로는 유지한다. 이 변경은 목록 화면의 동작만 바꾼다.

## 검증

- `pnpm build` 또는 관련 타입 검사를 실행한다.
- 공지 없음, 본문 줄바꿈, 열기·닫기와 키보드 조작을 확인한다.
