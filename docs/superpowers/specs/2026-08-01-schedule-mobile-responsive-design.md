# 스케줄 모바일 반응형 디자인

## 범위

`/schedule`의 목록, 생성, 상세 화면을 모바일에서 사용할 수 있게 한다. 데이터, 권한, URL, 서버 액션, 테스트 셀렉터와 기존 데스크톱 정보 구조는 바꾸지 않는다.

## 반응형 규칙

- 좁은 화면에서는 본문 여백을 줄이고, 가로로 나란한 영역을 한 열로 쌓는다.
- 목록 카드는 제목·상태·설명을 먼저 보이고, 아바타와 응답 현황은 그 아래에 배치한다.
- 생성 화면의 편집 폼과 미리보기/마감 설정은 한 열로 쌓고, 두 달 달력도 세로로 배치한다.
- 상세 화면의 제목과 동작 버튼, 응답 현황, 확정 배너, 추천 카드, 두 시간 격자는 각각 한 열로 쌓는다.
- 시간 격자는 날짜별 칸의 터치 가능한 폭을 줄이지 않는다. 표시 폭이 부족하면 해당 격자 안에서 가로 스크롤한다.
- 충분한 폭에서는 현재 데스크톱 배치를 유지한다.

## 구현 경계

- 기존 WDS 토큰과 컴포넌트를 사용한다.
- 새 라이브러리, 모바일 전용 경로·컴포넌트, API 변경은 만들지 않는다.
- 반응형 스타일은 스케줄 화면에만 한정한다.

## 검증

- 목록·생성·상세 화면에서 좁은 폭에 가로 넘침이 없는지 확인한다. 시간 격자 내부의 가로 스크롤은 예외다.
- 격자 터치 드래그, 링크 복사, 일정 생성·확정·저장 버튼의 기존 동작을 유지한다.
- 타입 검사와 관련 테스트를 실행한다.
