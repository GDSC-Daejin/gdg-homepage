# 도감봇 희귀도·확률 설계

## 목표

제1세대 151종마다 희귀도, 출현 가중치, 기본 몬스터볼 포획률을 둔다. 하루 세 번의 출현은 가중치 기반 무복원 추첨으로 선택하며, 포획 성공은 해당 포켓몬의 개별 포획률을 사용한다. 이 정보는 회원이 도감에서 모두 조회할 수 있다.

## 희귀도와 기본값

| 희귀도 | 출현 가중치 | 기본 몬스터볼 포획률 |
|---|---:|---:|
| 일반 | 100 | 70% |
| 흔치않음 | 55 | 60% |
| 희귀 | 25 | 48% |
| 매우 희귀 | 12 | 36% |
| 전설/환상 | 8 | 28% |

가중치는 같은 날 세 마리를 중복 없이 뽑을 때의 상대 확률이다. 포획률은 출현 이후 개인이 몬스터볼을 던졌을 때의 성공 확률이다.

## 배정 원칙

- 일반 포켓몬의 3단계 진화 계열은 기본형·중간형·최종형을 일반·흔치않음·희귀로 배정한다.
- 2단계 진화 계열은 기본형·최종형을 일반·흔치않음으로 배정한다.
- 스타터 계열은 일반 포켓몬보다 한 단계 높게 배정한다.
- 미뇽·신뇽·망나뇽은 흔치않음·희귀·매우 희귀로 배정한다.
- 럭키, 캥카, 쁘사이저, 켄타로스, 라프라스, 잠만보, 폴리곤, 프테라와 화석 포켓몬 계열은 실제 게임 내 희소성을 반영해 기본 원칙보다 한 단계 높게 배정한다.
- 프리져, 썬더, 파이어, 뮤츠, 뮤는 전설/환상으로 배정한다.

각 포켓몬의 최종 배정은 마이그레이션의 명시적 데이터로 고정한다. 자동 진화 판정은 사용하지 않아 운영 중 이름·세대·폼 변경에 영향을 받지 않는다.

## 도감 확률표

- `/pokedex`에 `내 도감`과 `확률표` 탭을 둔다.
- `확률표` 탭 상단에는 희귀도별 출현 가중치와 기본 몬스터볼 포획률 기준표를 둔다.
- 그 아래에는 151종 전체를 번호, 이미지, 이름, 희귀도, 출현 가중치, 기본 몬스터볼 포획률 순서로 표시한다. 포획하지 않은 포켓몬도 이름과 이미지를 공개한다.
- 출현 가중치 옆에는 “하루 3회, 가중치 비례·중복 없이 선정”이라는 안내를 표시한다. 앞선 추첨 결과에 따라 이후 확률이 달라지므로 고정 퍼센트 대신 실제 선정 기준인 가중치를 공개한다.

## 데이터와 보안

- `pokemon_catalog`에 공개 정보인 `rarity`, `spawn_weight`, 기존 `catch_rate`를 저장한다.
- 회원 읽기 정책은 확률표 조회를 허용한다.
- 기존 포획 RPC는 `pokemon_catalog.catch_rate`를 계속 사용한다.
- 일일 예약 크론은 `pokemon_catalog.spawn_weight`를 사용한다.

## 동작과 오류 처리

- 활성 포켓몬이 세 마리 미만이면 기존처럼 예약을 만들지 않는다.
- 가중치가 0 이하이거나 포획률이 0~1 범위를 벗어나면 DB 제약으로 저장을 막는다.
- 기존 출현과 포획 기록은 포켓몬 ID를 참조하므로 확률 도입 후에도 과거 기록이 바뀌지 않는다.

## 검증

- 가중치 추첨은 중복 없이 세 종을 반환하고, 높은 가중치가 낮은 가중치보다 우선되도록 고정 난수 테스트를 둔다.
- 마이그레이션 테스트로 151종 모두에 희귀도와 출현 가중치가 생성되고, 전설/환상 및 미뇽 계열의 등급을 확인한다.
- 도감 페이지 테스트로 두 탭, 희귀도 기준표, 개별 확률 열을 확인한다.
- 전체 테스트와 타입 검사를 실행한다.
