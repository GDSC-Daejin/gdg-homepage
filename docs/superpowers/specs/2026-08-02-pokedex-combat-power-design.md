# 도감봇 전투력 설계

## 목표

포켓몬마다 Pokémon GO식 전투력 범위를 두고, 야생 포켓몬이 출현할 때마다 그 범위 안의 전투력을 하나 생성한다. 같은 출현에서 포획한 회원은 같은 전투력을 가지며, 다음 출현에서는 다른 전투력이 생성된다.

화면에서는 CP나 개체값 대신 모두 `전투력`으로 표기한다.

## 데이터

- `pokemon_catalog`에 종별 `cp_min`, `cp_max`를 저장한다. 기본형·중간 진화·최종 진화·희귀·전설에 따라 범위가 높아진다.
- `pokemon_appearances`에 `combat_power`를 저장한다. 출현 예약을 생성할 때 종별 범위 안의 정수를 한 번 뽑아 넣고 이후 변경하지 않는다.
- 기존 출현과 포획 기록은 전투력이 없으므로 `null`을 유지한다.

## 생성과 보안

- 일일 출현 예약 크론과 수동 테스트 출현 SQL 모두 `combat_power`를 생성한다.
- 전투력 난수 생성은 DB에서 수행한다. Slack 이벤트·회원 브라우저 입력으로 전투력을 바꿀 수 없다.
- 포획 RPC는 출현 ID를 이미 참조하므로 전투력 값을 별도로 받아들이지 않는다.

## 표시

- Slack 출현 메시지: `야생의 피카츄가 나타났어요! 전투력 542`.
- 포켓몬 상세 페이지: 내가 포획한 기록별 전투력과 사용한 볼을 표시한다.
- 포획 회원 표: 회원, 포획 시각, 사용 볼, 전투력을 표시한다. 전투력 내림차순으로 정렬해 같은 종의 순위를 보여준다.
- 전투력이 없는 과거 기록은 `기록 없음`으로 표시하고 순위에서는 제외한다.

## 범위 기준

종별 값은 실제 Pokémon GO의 상대적인 전투력 감각을 따르되, 외부 게임 데이터를 그대로 복제하지 않는 서비스용 범위로 저장한다.

| 분류 | 전투력 범위 |
|---|---:|
| 일반 기본형 | 120–550 |
| 일반 중간 진화 | 450–1,000 |
| 일반 최종 진화 | 900–2,000 |
| 희귀 단일·최종 포켓몬 | 1,400–2,500 |
| 전설/환상 | 2,200–3,500 |

스타터, 미뇽 계열, 라프라스, 잠만보 등은 기존 희귀도 배정에 맞는 한 단계 높은 범위를 사용한다. 151종의 최종 범위는 마이그레이션에 명시한다.

## 검증

- 마이그레이션 테스트로 전투력 범위와 출현 전투력 제약을 확인한다.
- 출현 메시지 테스트로 전투력 표기를 확인한다.
- 상세 도감 테스트로 내 포획 기록과 회원별 전투력 순위를 확인한다.
- 전체 테스트와 타입 검사를 실행한다.
