# 도감봇 아침형 출현 설계

## 목표

하루 다섯 출현을 아침형 1마리, 낮형 3마리, 저녁형 1마리로 예약한다.

## 활동 시간대

| 분류 | 출현 수 | KST 시간 |
| --- | ---: | --- |
| 아침형 | 1 | 07:00–11:00 |
| 낮형 | 3 | 11:00–19:00 |
| 저녁형 | 1 | 19:00–23:00 |

각 시간대 안에서만 포켓몬을 고르고, 체류 시간을 포함해 같은 날 출현끼리 겹치지 않게 예약한다. 시간은 매일 독립적으로 랜덤 선택하며, 전날과 같은 시각을 금지하지 않는다.

## 아침형 포켓몬

다음 아홉 종을 모두 아침형으로 분류한다.

- 보통: 구구, 깨비참, 두두, 캐터피
- 낮은 확률: 피죤, 깨비드릴조, 파오리
- 희귀: 피죤투, 두트리오

기존 저녁형 포켓몬 분류는 유지한다. 나머지 활성 포켓몬은 낮형이다.

## 데이터와 예약

`pokemon_catalog.activity_period`는 `morning`, `day`, `night` 세 값을 가진다. 일일 예약은 각 분류에서 각각 1, 3, 1마리를 가중치에 따라 중복 없이 뽑아 해당 시간대에 배치한다.

아침형·저녁형 후보가 하나도 없거나 낮형 후보가 세 종보다 적으면 예약을 만들지 않고 오류를 반환한다.

## 검증

- 아침형 후보 아홉 종만 `morning`으로 분류한다.
- 하루 출현은 정확히 다섯 개이며, 분류별 수가 1·3·1이다.
- 각 출현은 자기 시간대 안에 있고, 체류 시간이 겹치지 않는다.
