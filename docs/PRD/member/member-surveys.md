# 설문 목록 (회원)

## 페이지 기본 정보

| 항목 | 내용 |
|---|---|
| 라우트 | /surveys |
| 접근 권한 | 회원 (`requireProfile`) |
| 한 줄 목적 | 현재 열려 있는 설문 목록을 보고, 응답 여부를 확인하며 상세로 이동한다 |
| 대상 사용자 | 참여 가능한 설문을 찾는 회원 |

## 페이지 목적 · 사용자 목표

- 지금 열려 있는(`is_open = true`) 설문만 골라본다.
- 내가 이미 응답한 설문인지 아닌지 한눈에 구분한다.
- 미응답 설문을 눌러 응답 페이지로 이동한다.

## 정보 구조 (Information Architecture)

1. **페이지 헤더** — "설문" + "참여 가능한 설문이에요" 설명
2. **설문 리스트** — 열린 설문을 생성일 최신순으로 카드 나열, 각 카드 우측에 응답 여부 배지. 없으면 빈 상태

## 주요 UI 요소 · 표시 데이터

- **설문 카드** (건별, 클릭 시 `/surveys/[id]`로 이동):
  - 제목(`title`) — 좌측
  - 응답 상태 배지 — 우측: 응답 완료(neutral) / 미응답(primary)
- **빈 상태**: "열린 설문이 없어요"

## 상태 (States)

- 열린 설문 없음 → EmptyState
- 마감된(`is_open = false`) 설문은 이 목록에 노출되지 않음
- 응답 여부는 현재 로그인한 회원 기준으로만 판정(다른 회원의 응답 여부와 무관)

## 인터랙션 · 액션

- 카드 클릭 → 해당 설문 상세로 이동(응답 완료 여부와 무관하게 이동은 항상 가능 — 상세에서 완료/마감 안내 처리)
- 필터/검색 없음

## 디자인 의도 · 강조점

- "미응답" 배지가 행동을 유도하는 핵심 신호 — primary 톤으로 눈에 띄게, "응답 완료"는 neutral로 조용히 처리해 대비를 강조.
- 목록 스캔 시 어떤 설문에 아직 참여 안 했는지 즉시 판별 가능해야 함.

## 반응형 · 접근성 노트

- 카드 내 제목과 배지가 좌우로 배치되므로 모바일 좁은 화면에서 줄바꿈/겹침 방지.
- 배지 텍스트("응답 완료"/"미응답")로 상태를 표현해 색에만 의존하지 않음.
