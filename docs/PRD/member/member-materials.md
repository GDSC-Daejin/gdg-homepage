# 자료실

## 페이지 기본 정보
| 항목 | 내용 |
|---|---|
| 라우트 | /materials |
| 접근 권한 | 회원 |
| 한 줄 목적 | 세션·스터디 자료를 표 형태로 모아보고 원문 링크로 이동한다 |
| 대상 사용자 | 모든 회원 |

## 페이지 목적 · 사용자 목표
- 특정 세션/스터디 자료를 찾아 연다
- 자료의 유형, 관련 이벤트, 등록일을 훑어본다

## 정보 구조 (Information Architecture)
- 헤더: "자료실" + "세션 및 스터디 자료를 확인해요"
- 단일 테이블 카드: 제목 / 유형 / 이벤트 / 날짜 / 링크 5개 컬럼

## 주요 UI 요소 · 표시 데이터
- 데이터 출처: Notion 데이터베이스 연동(fetchMaterials)
- 컬럼별 표시: 제목(빈 값이면 "(제목 없음)"), 유형(뱃지, neutral 톤, 값 없으면 비표시), 이벤트명(없으면 "-"), 날짜(없으면 "-", 있으면 포맷된 날짜), 링크(자료 URL "자료 열기" + 항상 존재하는 "노션에서 보기" 링크)
- 두 링크 모두 새 탭(target=_blank)으로 열림

## 상태 (States)
- Notion 연동 미설정/오류: "자료를 불러오지 못했어요" + 구체적 에러 메시지
- 자료 0건: "등록된 자료가 없어요" 빈 상태
- 정상: 테이블 렌더링

## 인터랙션 · 액션
- "자료 열기" 클릭 → 실제 자료 URL로 새 탭 이동 (URL 없는 행은 링크 미표시)
- "노션에서 보기" 클릭 → 해당 Notion 페이지로 새 탭 이동
- 필터/검색/정렬 등 인터랙션 없음 (Notion 쪽 정렬 순서를 그대로 따름)

## 디자인 의도 · 강조점
- 정보 탐색형 화면 — 표 가독성이 최우선(행 구분선, 헤더 강조)
- 유형 뱃지로 자료 종류를 빠르게 스캔할 수 있게
- 외부 연동(Notion) 실패를 사용자가 이해할 수 있는 문구로 노출하는 것이 중요

## 반응형 · 접근성 노트
- 테이블은 가로 스크롤 가능하도록 처리(모바일 좁은 화면 대응, 이미 overflow-x-auto 구현)
- 링크 텍스트만으로 목적지 구분 가능(색상 의존 최소화)
