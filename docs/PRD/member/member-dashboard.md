# 회원 홈 (대시보드)

## 페이지 기본 정보
| 항목 | 내용 |
|---|---|
| 라우트 | / (member layout) |
| 접근 권한 | 회원 (name 등록 완료된 로그인 사용자) |
| 한 줄 목적 | 로그인 후 가장 먼저 보는 화면으로, 최신 공지와 이벤트 목록을 보여준다 |
| 대상 사용자 | 지원자/멤버/관리자 공통 (사이드바 내 "홈") |

## 페이지 목적 · 사용자 목표
- 놓친 공지가 있는지 바로 확인한다
- 다가오는 이벤트를 보고 참여 여부를 판단한다
- 지난 이벤트를 월별로 돌아본다

## 정보 구조 (Information Architecture)
1. 최신 공지 배너 (있을 때만) — 클릭 시 공지 상세로 이동
2. "다가오는 이벤트" 섹션 — 카드 그리드
3. "지난 이벤트" 섹션 — 월 필터 + 카드 그리드

## 주요 UI 요소 · 표시 데이터
- 공지 배너: "공지" 뱃지 + 공지 제목 (published=true 중 최신 1건만)
- 이벤트 카드: 유형 뱃지(세션/스터디/데브페스트, 각각 톤 primary/success/warning), 제목, 일시, 장소(있을 때만), "N / 정원 명 신청" (정원 없으면 신청자 수만)
- 다가오는 이벤트: 시작일 오름차순
- 지난 이벤트: 기본값은 최근 3개월, 월 필터 드롭다운으로 "최근 3개월/전체/개별 월" 선택 가능

## 상태 (States)
- 공지 없음: 배너 미표시
- 다가오는 이벤트 없음: "예정된 이벤트가 없어요" 빈 상태
- 지난 이벤트 없음(필터 결과 포함): "지난 이벤트가 없어요" 빈 상태

## 인터랙션 · 액션
- 공지 배너 클릭 → 공지 상세 페이지 이동
- 이벤트 카드 클릭 → 이벤트 상세 페이지 이동 (카드 전체가 링크, hover 시 그림자 강조)
- 월 필터 변경 → 같은 페이지에서 지난 이벤트 목록만 갱신

## 디자인 의도 · 강조점
- 첫 진입 화면이므로 공지 배너는 눈에 띄되 과하지 않게(브랜드 소프트 컬러 톤)
- 다가오는 이벤트가 지난 이벤트보다 우선순위 높음 — 화면 상단에 배치, 시각적 비중도 더 크게
- 이벤트 유형 뱃지 색상으로 한눈에 세션/스터디/데브페스트 구분되게

## 반응형 · 접근성 노트
- 이벤트 카드 그리드는 모바일 1열 / 사맥 이상 2열
- 유형 구분을 색상에만 의존하지 않고 텍스트 라벨 병기(이미 구현됨) 유지
