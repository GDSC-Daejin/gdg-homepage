# 프로필 등록 (온보딩)

## 페이지 기본 정보
| 항목 | 내용 |
|---|---|
| 라우트 | /onboarding |
| 접근 권한 | 로그인했지만 아직 이름(name)을 등록하지 않은 사용자 전용 |
| 한 줄 목적 | 최초 로그인 직후 활동에 필요한 기본 정보를 입력받는다 |
| 대상 사용자 | 신규 가입자(첫 로그인) |

## 페이지 목적 · 사용자 목표
- 이름을 포함한 기본 정보를 입력해 서비스 이용을 시작한다
- 입력 완료 즉시 홈으로 넘어간다

## 정보 구조 (Information Architecture)
- 좁은 폭(max-width) 단일 컬럼 레이아웃, 중앙 정렬
- 헤더: "프로필 등록" + "동아리 활동을 위해 기본 정보를 입력해주세요"
- 단일 폼 카드

## 주요 UI 요소 · 표시 데이터
- 입력 필드: 이름(필수), 학번, 전공, 전화번호
- 관심 분야 체크박스: Android/Web/iOS/ML/Cloud/Design (복수 선택, 초기값 모두 미체크)
- 저장 버튼 1개

## 상태 (States)
- name이 이미 등록된 사용자가 접근 시 자동으로 홈("/")으로 리다이렉트 — 이 화면은 최초 1회만 노출
- 미로그인 시 로그인 페이지로 리다이렉트
- 제출 중: 버튼 비활성화
- 제출 실패: 폼 하단 에러 텍스트
- 제출 성공 시 이름이 채워지므로 이후 재방문 시 홈으로 우회됨(별도 성공 화면 없음)

## 인터랙션 · 액션
- 폼 제출(이름 필수) → 성공 시 다음 진입부터 온보딩을 건너뜀
- 실패 시 인라인 에러만 노출, 입력값 유지

## 디자인 의도 · 강조점
- 가입 직후 유일한 필수 관문 화면 — 부담 없이 빠르게 끝낼 수 있도록 간결하게
- 이름만 필수이고 나머지는 선택 사항임을 시각적으로 구분(선택 필드라는 인상)
- 관심 분야는 이후 개인화(뱃지, 추천 등)에 쓰일 수 있음을 암시하는 톤으로 표현 가능

## 반응형 · 접근성 노트
- 모바일에서도 단일 컬럼 그대로 사용 가능한 폭
- 체크박스 그룹에 그룹 레이블("관심 분야") 명확히 연결
