# Team

## 페이지 기본 정보

| 항목 | 내용 |
|---|---|
| 라우트 | /team |
| 접근 권한 | 비로그인 (공개) |
| 한 줄 목적 | 운영진 구성원과 역할을 소개한다 |
| 대상 사용자 | 누가 운영하는지 궁금한 예비 회원·외부 방문자 |

## 정보 구조

1. **뒤로가기 네비** — "← 로그인으로 돌아가기"
2. **Hero / 타이틀** — "TEAM" + 한 줄 설명 ("GDG on Campus DJU 운영진입니다")
3. **운영진 리스트** — 아바타 + 이름 + 역할, 세로 나열 4명

## 주요 UI 요소 · 표시 데이터

멤버당 필드:
- 아바타 — 이니셜 2글자, Google Blue→Green 그라데이션 원형 배경
- 이름
- 역할 — 직책 · 담당 트랙 (예: "회장 · 웹트랙")

현재 등록된 4인: 김도현(회장·웹트랙), 이서윤(부회장·AI트랙), 박준영(운영진·안드로이드트랙), 최지아(운영진·클라우드트랙).

## 상태 (States)

- 정적 리스트. 빈 상태/로딩 없음.

## 인터랙션 · 액션

- 읽기 전용. 멤버 클릭 시 프로필/SNS 연결 등은 현재 없음.

## 디자인 의도 · 강조점

- 이니셜 아바타 + 그라데이션이 유일한 비주얼 요소 — 실제 프로필 사진 도입 여부가 재설계의 주요 결정 포인트.
- 직책(회장/부회장/운영진)과 트랙(웹/AI/안드로이드/클라우드)이 함께 표기되어 "누가 어떤 영역을 담당하는지"가 핵심 정보 — 트랙별 색상 코딩(로그인 페이지의 LEARN/BUILD/CONNECT나 배지 색과 일관성 있게)을 적용하면 팀 구조가 더 잘 읽힘.
- 세로 리스트는 인원이 적을 때는 적절하지만, 향후 인원이 늘면 그리드/카드형으로 전환하는 것을 고려.

## 반응형 · 접근성 노트

- 단일 컬럼 세로 리스트, `max-w-2xl` — 모바일에서도 동일하게 자연스러움.
- 아바타의 이니셜 텍스트 대비(흰 텍스트 on 그라데이션) 확인 필요.
