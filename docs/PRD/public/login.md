# Login

## 페이지 기본 정보

| 항목 | 내용 |
|---|---|
| 라우트 | /login |
| 접근 권한 | 비로그인 (공개) |
| 한 줄 목적 | GDG on Campus DJU의 브랜드를 각인시키고 Google 로그인으로 전환시킨다 |
| 대상 사용자 | 아직 가입하지 않은 예비 회원, 커뮤니티를 처음 발견한 방문자 |

가장 공들여 구현된 페이지로, 다른 4개 공개 페이지(about/events/projects/team)의 콘텐츠 원형(연혁, 다음 모임, 대표 프로젝트, 후기)을 압축해 하나의 풀스크린 히어로에 담고 있다. 데스크톱에서는 좌/중앙/우 3분할 절대배치, 모바일에서는 세로 스택으로 전환되는 반응형 구조다.

## 정보 구조

데스크톱 기준 좌→중앙→우, 모바일 기준 위→아래 순서:

1. **상단 네비게이션** — 로고(GDG 4색 점 + 워드마크), 중앙 pill 메뉴(ABOUT/EVENTS/PROJECTS/TEAM), 우측 "MEMBERS" 라벨
2. **좌측: 브랜드 헤드라인 영역**
   - 모집 상태 배지 ("2026 신규 멤버 모집 중", 초록 점 인디케이터)
   - 메인 헤드라인 "BUILD WITH GOOGLE." (2줄, 2번째 줄은 Google 4색 그라데이션)
   - 리드 문장 (커뮤니티 한 줄 정체성)
   - 기술 배지 6종 (Web/Android/AI-ML/Cloud/Flutter/UX, 일부 색상 강조)
   - LEARN·BUILD·CONNECT 3항목 (색 점 + 타이틀 + 한 줄 설명)
3. **중앙: 3D 오브(구체) 비주얼 클러스터** — Google 4색 그라데이션 구체 4개가 겹쳐진 순수 장식 요소, 부유 애니메이션
4. **우측: 소셜 프루프 패널**
   - 훅 문장 + 기술 스택 pill 5종
   - NEXT MEETUP 배지 (날짜 + 장소/트랙 2줄)
   - FEATURED PROJECTS (3건, 프로젝트 페이지와 동일 데이터 축소판)
   - 회원 후기 (인용구 + 아바타 + 이름/트랙)
5. **좌하단: 통계 + 언어 토글**
   - 활동 멤버 150+ · 진행 프로젝트 12 · 스터디 팀 5
   - KOR/ENG pill 토글 (본문 카피 언어 전환용, 현재 하단 카피 문단에만 영향)
6. **하단 카피 문단** — 언어 토글에 따라 한/영 전환되는 짧은 소개 문장
7. **최종 CTA** — "Google로 로그인하기" 버튼 (Google 로고 + 텍스트 + 화살표 아이콘), 클릭 시 Supabase OAuth(Google) 실행
8. **푸터 문구** — "© 2026 GDG on Campus · Daejin University"

## 주요 UI 요소 · 표시 데이터

- 배지 텍스트, 헤드라인, 리드 문장, 기술 배지 리스트 — 하드코딩된 카피 상수
- 통계 3종: 150+ / 12 / 5
- NEXT MEETUP: "03.14 · DevFest Warm-up" + 2줄 설명 (events 페이지 최신 항목과 동기화 필요한 데이터)
- FEATURED PROJECTS: 3건 (projects 페이지의 부분집합)
- 후기 1건: 인용구 + 이름(김도현) + 트랙(웹트랙·3기) + 이니셜 아바타
- 언어 토글 상태(KOR/ENG) — 클라이언트 로컬 state, 하단 카피 문단만 전환됨 (다른 텍스트는 미전환)

## 상태 (States)

- 로그인 버튼 클릭 → Supabase `signInWithOAuth` 호출, 콜백 이후 `/auth/callback`으로 리다이렉트. 로딩 중 버튼 피드백/비활성화 상태는 현재 없음.
- 언어 토글: KOR(기본 선택) / ENG 두 상태, pill 활성화 스타일(흰 배경)로 구분.
- 에러 상태(OAuth 실패 등) 처리 없음 — 재설계 시 실패 피드백 고려 필요.

## 인터랙션 · 액션

- 상단 pill 메뉴 클릭 → 각 공개 페이지(about/events/projects/team)로 이동.
- "MEMBERS" 라벨 — 현재 클릭 동작 없는 정적 텍스트(향후 회원 전용 영역 링크로 의도된 것으로 추정).
- 언어 토글 클릭 → 하단 카피 문단 언어 전환.
- CTA 버튼 클릭 → Google OAuth 로그인 시작.
- 장식 요소(오브, 컨페티, 글로우)는 순수 애니메이션이며 인터랙션 없음.

## 디자인 의도 · 강조점

- Google 브랜드 4색(Blue/Red/Yellow/Green)을 헤드라인 그라데이션·오브·배지·통계 곳곳에 일관되게 사용 — 이 페이지가 전체 공개 페이지군의 톤 기준점 역할.
- 정보 밀도가 높다(헤드라인+통계+모임+프로젝트+후기 5종이 한 화면에 공존) — 시선 우선순위는 헤드라인 → CTA 순으로, 나머지는 신뢰 보강(social proof) 요소로 취급.
- 3D 오브 클러스터는 순수 장식이지만 화면 중심을 차지 — 재설계 시 이 비주얼의 존치/대체 여부가 핵심 결정 포인트.
- CTA는 화면 최하단 고정형으로 항상 접근 가능해야 함 (데스크톱은 절대 위치 고정).
- 언어 토글이 현재 카피 전체가 아닌 일부 문단에만 적용되는 점은 재설계 시 스코프를 명확히 할 필요(전체 다국어화 여부는 별도 결정 사항).

## 반응형 · 접근성 노트

- 3단계 브레이크포인트: 모바일(기본, 세로 스택) / 640px(sm, 패딩·폰트 확대) / 1024px(lg, 절대배치 3분할 풀스크린 히어로).
- 데스크톱은 `overflow: hidden` 풀스크린 고정 히어로 — 콘텐츠가 늘어나면 스크롤 없이 잘릴 위험, 콘텐츠 길이 통제 필요.
- 장식용 애니메이션 요소(오브, 컨페티, 글로우)는 `pointer-events: none` 처리되어 있음 — 모션 감소 선호(`prefers-reduced-motion`) 대응은 현재 없음, 접근성 보강 여지.
- 그라데이션 텍스트(헤드라인) 대비 확인 필요, 저채도 회색 텍스트(rgba white 0.5~0.7)가 다수 사용됨.
