# About

## 페이지 기본 정보

| 항목 | 내용 |
|---|---|
| 라우트 | /about |
| 접근 권한 | 비로그인 (공개) |
| 한 줄 목적 | GDG on Campus DJU가 어떤 커뮤니티인지 소개하고 연혁을 보여준다 |
| 대상 사용자 | 가입을 고민 중인 예비 회원, 커뮤니티를 처음 접하는 방문자 |

현재 구현은 로그인 화면(`/login`)에서 뻗어나가는 서브페이지로, 뒤로가기 링크 하나와 본문·연혁 리스트만 있는 최소 상태다. 로그인 페이지가 이미 브랜드 톤(Google 4색, 다크 배경, `BUILD WITH GOOGLE` 헤드라인, LEARN/BUILD/CONNECT, 활동 통계 150+/12/5)을 확립해두었으므로, About은 그 세계관을 이어받아 "왜/무엇을" 더 깊이 설명하는 역할로 확장한다.

## 정보 구조 (섹션 취사선택)

1. **뒤로가기 네비** — "← 로그인으로 돌아가기" 텍스트 링크 (현재 유일한 내비게이션)
2. **Hero / 타이틀** — "ABOUT" 대제목
3. **소개 본문** — 커뮤니티 정체성 설명 문단 (아래 실제 카피)
4. **HISTORY 타임라인** — 연도별 마일스톤 4건

## 주요 UI 요소 · 표시 데이터

- 소개 문단 (그대로 유지 가능한 실제 카피):
  "GDG on Campus DJU는 대진대학교 학생 개발자들이 구글 기술을 함께 배우고, 실제 서비스를 만들어보고, 서로의 성장을 돕는 커뮤니티입니다. 매주 스터디와 코드리뷰, 정기 해커톤과 DevFest를 통해 아이디어를 제품으로 완성하는 경험을 제공합니다."
- HISTORY 리스트 (연도 + 설명, 좌측 연도는 Google Blue 강조):
  - 2023 — GDG on Campus DJU 창립
  - 2024 — 첫 DevFest 개최, 회원 50명 돌파
  - 2025 — 웹·안드로이드·AI 스터디 트랙 신설
  - 2026 — 회원 150명 돌파, 12개 프로젝트 진행 중

## 상태 (States)

- 정적 콘텐츠 페이지, 별도 로딩/에러/빈 상태 없음.

## 인터랙션 · 액션

- 상단 링크 클릭 시 `/login`으로 이동. 그 외 인터랙션 없음 (읽기 전용).

## 디자인 의도 · 강조점

- 로그인 페이지의 다크 배경 + Google 4색 포인트 언어를 계승.
- 현재는 "제목 + 문단 + 타임라인"뿐인 매우 얇은 페이지 — 재설계 시 Hero(타이틀+한 줄 요약), 소개 본문, 타임라인 외에 로그인 페이지에 이미 있는 LEARN/BUILD/CONNECT 카드나 활동 통계(150+/12/5)를 재사용해 소개 페이지다운 밀도를 보강하는 것을 고려.
- 타임라인은 연도가 핵심 앵커이므로 스캔하기 쉬운 좌-우 정렬 유지, 최신 연도(2026)를 시각적으로 강조하면 좋음.
- 상단 네비게이션이 로그인 페이지처럼 ABOUT/EVENTS/PROJECTS/TEAM 상호 이동 nav로 통일되면 사용성이 좋아짐 (현재는 로그인으로 돌아가는 링크뿐).

## 반응형 · 접근성 노트

- 현재 `max-w-2xl` 단일 컬럼, 모바일 우선 구조 — 데스크톱에서도 과도하게 넓어지지 않도록 유지.
- 텍스트 대비: 흰 배경 위 `white/70`, `white/60` 등 저채도 텍스트가 많아 대비 확인 필요.
