# 공지사항 목록 (어드민)

## 페이지 기본 정보
| 항목 | 내용 |
|---|---|
| 라우트 | /admin/notices |
| 접근 권한 | 어드민 |
| 한 줄 목적 | 등록된 공지 목록을 확인하고 새 공지 작성으로 진입한다 |
| 대상 사용자 | 공지를 작성·관리하는 운영진 |

## 페이지 목적 · 사용자 목표
- 발행됨/미발행 상태를 포함해 전체 공지 목록을 한눈에 훑어본다
- 특정 공지를 클릭해 상세(수정) 화면으로 이동한다
- 새 공지 작성 화면으로 이동한다

## 정보 구조 (Information Architecture)
1. 페이지 헤더 + 우측 상단 "공지 작성" 버튼(CTA)
2. 공지 카드 리스트 (최신 작성순), 카드마다 상태 배지 + 제목 + 날짜 메타

## 주요 UI 요소 · 표시 데이터
- 헤더 액션 버튼: "공지 작성" → /admin/notices/new 로 이동
- 각 공지 카드: 발행 상태 배지("발행됨"=성공톤 / "미발행"=중립톤), 제목, 날짜 메타(발행됨이면 "발행 {날짜}", 아니면 "작성 {날짜}")
- 카드 전체가 클릭 가능한 링크 (상세로 이동)

## 상태 (States)
- 등록된 공지가 없을 때: 빈 상태("등록된 공지가 없어요")
- 카드 hover: 그림자 강조로 클릭 가능함을 시사

## 인터랙션 · 액션
- 카드 클릭 → 해당 공지 상세(수정) 페이지로 이동
- "공지 작성" 버튼 클릭 → 작성 페이지로 이동

## 디자인 의도 · 강조점
- 발행 여부가 목록에서 즉시 구분되어야 함 — 배지가 가장 먼저 시선을 끄는 요소
- 리스트는 훑어보기 용도이므로 정보 밀도는 낮게, 제목이 주인공
- CTA(공지 작성)는 항상 눈에 띄는 위치(헤더 우측)에 고정

## 반응형 · 접근성 노트
- 좁은 화면에서 카드 내부 배지+제목 줄바꿈 허용
- 상태는 배지 색상 + 텍스트("발행됨"/"미발행")를 함께 표기
- 카드 링크는 키보드 포커스로 접근 가능해야 함
