# 어드민 출석 관리

## 페이지 기본 정보
| 항목 | 내용 |
|---|---|
| 라우트 | /admin/attendance |
| 접근 권한 | 어드민 |
| 한 줄 목적 | 활동 회원 전체의 이벤트 출석률을 점검하고, 저조한 회원에게 슬랙 경고를 일괄 발송한다 |
| 대상 사용자 | 동아리 운영진(관리자) |

## 페이지 목적 · 사용자 목표
- 활동 회원(status=active) 전원의 출석률을 한 번에 확인한다.
- 출석률이 기준(50%) 미만인 회원을 시각적으로 구분해낸다.
- 저조한 회원들에게 슬랙으로 출석 경고를 한 번에 발송한다.

## 정보 구조 (Information Architecture)
1. 페이지 헤더 — "출석 관리" 타이틀 + 설명 + 우측 액션 버튼("슬랙으로 발송")
2. 회원별 출석 테이블 (전체 폭, 이름순 정렬)

## 주요 UI 요소 · 표시 데이터
- **헤더 액션**: "슬랙으로 발송" 버튼(secondary) — 클릭 시 처리 결과 메시지가 버튼 아래 표시.
- **테이블 컬럼**: 이름, 학번, 확정 신청 수(지난 이벤트 중 confirmed 등록 건수), 출석 수, 출석률(%) + 기준 미달 시 "경고" 뱃지(warning).
- 대상은 활동 회원(role=member, status=active) 전체, 지난 이벤트(시작일이 과거인 이벤트) 기준으로 집계.
- 확정 신청이 0건인 회원은 출석률 "-"로 표시(경고 대상 아님).

## 상태 (States)
- 활동 회원이 없음 → "활동 회원이 없어요" 빈 상태.
- 발송 처리 중 버튼 비활성화.
- 발송 성공 시 "출석 경고 N명에게 슬랙 알림을 보냈어요" 또는 "출석률 미달 회원이 없어요" 메시지.
- 발송 실패 시 에러 메시지(같은 자리에 텍스트로 표시).
- 출석률 50% 미만인 행에만 "경고" 뱃지 노출(그 외엔 숫자만).

## 인터랙션 · 액션
- "슬랙으로 발송" 클릭 → 서버 액션 호출 → 기준 미달 회원 전원에게 슬랙 알림 발송 → 결과 메시지 표시(별도 확인창 없음).
- 필터/검색 UI 없음 — 활동 회원 전체를 한 번에 보여주는 단일 뷰.

## 디자인 의도 · 강조점
- "경고" 뱃지가 붙은 행이 리스트에서 즉시 눈에 띄어야 함 — 출석률 낮은 회원을 스캔하기 쉽게.
- 헤더의 발송 버튼은 목록 전체에 대한 일괄 액션이므로, 개별 행 액션과 구분되는 위치(헤더 우측)에 배치되어 있음 — 이 위계를 유지.
- 별도 필터가 없는 단순한 전체 목록이므로, 정렬/스캔 용이성(이름순)에 집중.

## 반응형 · 접근성 노트
- 테이블 가로 스크롤 허용.
- 경고 표시는 뱃지 텍스트("경고")를 동반하므로 색상 없이도 인지 가능.
- 발송 결과 메시지는 버튼과 가까운 위치에 배치되어 있어 스크린리더 사용자도 액션-결과 연결을 파악하기 쉬워야 함.
