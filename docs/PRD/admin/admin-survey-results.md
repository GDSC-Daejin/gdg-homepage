# 어드민 - 설문 결과

## 페이지 기본 정보
| 항목 | 내용 |
|---|---|
| 라우트 | /admin/surveys/[id]/results |
| 접근 권한 | 어드민 |
| 한 줄 목적 | 설문의 질문별 응답을 집계해서 보여준다 |
| 대상 사용자 | 운영진 |

## 페이지 목적 · 사용자 목표
- 설문에 몇 명이 응답했는지 확인한다.
- 질문별로 평점 분포(평균 포함) 또는 서술형 응답 전체를 확인한다.

## 정보 구조 (Information Architecture)
1. **헤더** — 설문 제목 + 설명("응답 N건")
2. **질문별 결과 카드 리스트** — 설문에 설정된 질문 순서대로, 질문마다 카드 하나

## 주요 UI 요소 · 표시 데이터
- **평점형 질문 카드**:
  - 질문 라벨
  - "평균 X.X점 (N명 응답)" — 응답 없으면 "-"
  - 1~5점 각각의 분포를 가로 막대 그래프로 표시(점수 라벨 + 바 + 응답 수), 최댓값 기준 상대 길이
- **서술형 질문 카드**:
  - 질문 라벨
  - 응답 목록을 카드형 리스트로 나열(각 응답 = 회색 배경 텍스트 블록)
  - 응답 없으면 "응답 없음" 텍스트

## 상태 (States)
- **질문 없음**: "질문이 없어요" 빈 상태(설문 자체에 질문이 하나도 없는 경우).
- **질문별 응답 없음**: 평점형은 평균 "-", 분포 막대 전부 0. 서술형은 "응답 없음" 문구.
- 이 페이지는 읽기 전용 조회 화면이라 별도 액션/에러 상태 없음.

## 인터랙션 · 액션
- 없음(순수 조회 페이지). 뒤로가기/네비게이션으로만 이탈.

## 디자인 의도 · 강조점
- 데이터 시각화가 핵심 — 평점 분포 막대 그래프의 가독성(1~5점 각 행, 응답 수 병기)이 가장 중요.
- 질문 유형(평점/서술)에 따라 완전히 다른 표현 방식을 쓰므로, 두 카드 타입이 한 페이지에 섞여도 각각의 역할이 명확히 구분되어야 함.
- 응답 건수(헤더의 "응답 N건")가 전체 참여도를 보여주는 최상위 지표.

## 반응형 · 접근성 노트
- 막대 그래프는 색상(primary)만으로 정보를 전달하지 않도록 점수·응답수 텍스트를 항상 병기(현재 구현 유지).
- 서술형 응답이 길어질 경우 카드가 세로로 늘어나므로 좁은 화면에서도 줄바꿈이 자연스러워야 함.
