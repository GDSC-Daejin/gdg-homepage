# 어드민 대시보드

## 페이지 기본 정보
| 항목 | 내용 |
|---|---|
| 라우트 | /admin |
| 접근 권한 | 어드민 |
| 한 줄 목적 | 동아리 운영 현황(회원·이벤트·출석·만족도·활동 랭킹)을 한 화면에서 훑어본다 |
| 대상 사용자 | 동아리 운영진(관리자) |

## 페이지 목적 · 사용자 목표
- 로그인 직후 동아리 전반 상태(회원 규모, 다가오는 일정, 최근 출석률)를 빠르게 파악한다.
- 최근 이벤트별 출석 성과와 세션 만족도를 비교해 운영 품질을 점검한다.
- 포인트 기준 활동 랭킹으로 적극적인 회원을 파악한다.

## 정보 구조 (Information Architecture)
1. 페이지 헤더 — "대시보드" 타이틀 + 설명
2. 요약 지표 카드 4개 (가로 배치)
3. 최근 이벤트 테이블 (최근 종료 이벤트 5건)
4. 2단 그리드: 월별 신규 가입 추이(막대 차트) / 세션별 만족도(가로 바)
5. 활동 랭킹 Top 10 테이블

## 주요 UI 요소 · 표시 데이터
- **요약 카드 4개**: 전체 회원 수(role=member), 활동 회원 수(status=active), 다가오는 이벤트 수(시작일 기준 미래), 최근 이벤트 평균 출석률(%, 최근 지난 이벤트 5개 기준, 힌트 텍스트 포함).
- **최근 이벤트 테이블**: 제목, 유형(세션/스터디/데브페스트 뱃지성 텍스트), 일시(KST), 확정 인원, 출석 인원, 출석률(%). 최대 5행.
- **월별 신규 가입 추이**: 최근 6개월 막대 그래프, 각 막대 위 숫자(해당 월 가입자 수), 하단 월 라벨. 최댓값 기준 상대 높이.
- **세션별 만족도**: 이벤트별 가로 진행바(설문 rating 문항 평균 ÷ 5), 이벤트명 + 평균 점수(소수 1자리) + 응답 수. 평균 높은 순 정렬.
- **활동 랭킹 Top 10 테이블**: 순위, 이름, 누적 포인트(포인트 로그 합산 내림차순).

## 상태 (States)
- 최근 이벤트 없음 → "지난 이벤트가 없어요" 빈 상태.
- 설문 응답 데이터 없음 → "설문 응답 데이터가 없어요" 빈 상태.
- 포인트 내역 없음 → "포인트 내역이 없어요" 빈 상태.
- 평균 출석률 계산 불가 시 "-" 표시.
- 서버 컴포넌트로 매 요청 최신 데이터(force-dynamic), 별도 로딩 스피너 없음.

## 인터랙션 · 액션
- 순수 조회 페이지. 클릭 가능한 액션 없음(필터/버튼 없음).
- 다른 페이지로의 링크도 없음 — 요약과 진입점 역할에 집중.

## 디자인 의도 · 강조점
- 최상단 4개 지표 카드가 시선을 먼저 받아야 함 — 동아리 "건강 상태"의 스냅샷.
- 최근 이벤트 표와 활동 랭킹 표는 같은 톤의 테이블이지만 우선순위가 다름(이벤트 운영 성과 vs 회원 참여도) — 구분되는 섹션 타이틀 필요.
- 막대 차트와 만족도 바는 나란히 두어 "성장 추세"와 "품질 지표"를 동시에 비교하게 한다.
- 색상은 하나의 강조색(primary)만 사용 — 여러 색을 쓰는 대신 대비와 위계로 구분.

## 반응형 · 접근성 노트
- 4개 지표 카드는 좁은 화면에서 2단 또는 1단으로 접히는 구조 고려.
- 테이블은 가로 스크롤 허용(overflow-x-auto).
- 만족도/출석률 등 수치 정보는 막대 색상뿐 아니라 텍스트(%, 점수)로 항상 병기되어 있어 색만으로 판단하지 않도록 유지.
