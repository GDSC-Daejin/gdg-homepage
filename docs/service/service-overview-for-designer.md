# 지금 우리 서비스, 어떻게 생겼나 (쉬운 소개)

> 디자이너가 "이 앱이 지금 뭐로 이루어져 있지?"를 빠르게 파악하기 위한 문서. 어려운 말 빼고 화면 중심으로 정리했어요. (개선 방향은 별도 문서 → [redesign-for-designer.md](redesign-for-designer.md))

---

## 한 줄 소개

**GDG on Campus 대진대** 동아리를 위한 웹앱이에요.
신입을 뽑고, 회원이 이벤트에 참여하고, 운영진이 뒤에서 관리하는 것까지 한 곳에서 해요.

---

## 세 종류의 사람이 써요

| 누구 | 어떤 사람 | 뭘 하나 |
|---|---|---|
| 👀 **처음 온 사람** | 아직 회원 아님 (비로그인) | 구경하고 → 지원함 |
| 🙋 **회원** | 지원 합격해서 들어온 사람 | 이벤트 참여, 활동 |
| 🛠 **운영진** | 동아리를 굴리는 스태프 | 관리 전반 |

로그인 여부와 역할에 따라 **보이는 화면이 완전히 달라져요.**

---

## 1. 처음 온 사람이 보는 것 (로그인 전)

동아리를 소개하고 지원을 받는 **홍보용 화면**들이에요.

- **첫 화면(랜딩)** — 알록달록한 3D 오브, "배우고, 만들고, 배포한다" 문구, 활동 소개
- **소개 / 운영진 / 프로젝트** — 동아리가 뭘 하는지 보여주는 페이지들
- **지원하기** — 로그인 없이 바로 지원서 작성 (이름·학번·전공 등 + 자기소개 3문항)
- **면접 예약** — 합격 후보에게만 링크로 열림

> 흐름: **첫 화면 → 지원하기 → (제출) → 결과는 이메일로 안내**

---

## 2. 회원이 보는 것 (로그인 후)

로그인하면 왼쪽에 **메뉴 11개**가 뜨는 앱 화면으로 바뀌어요.

| 메뉴 | 뭐 하는 곳 |
|---|---|
| **홈** | 다가오는 이벤트, 안 한 설문, 새 공지, 이번 달 포인트 요약 |
| **이벤트** | 이벤트 목록 → 신청 → 당일 출석 체크 |
| **공지** | 운영진 공지 읽기 |
| **회의록** | 모임 기록 (노션 연동) |
| **자유게시판** | 자유 글 |
| **질문답변** | 질문 올리고 답변 채택 |
| **설문** | 설문 응답 |
| **문의** | 운영진에게 문의 |
| **자료실** | 학습 자료 (노션 연동) |
| **프로필** | 내 정보, 영어 닉네임, 포인트, 뱃지 |
| **출석이력** | 내가 출석한 기록 |

> 회원 핵심 흐름: **이벤트 신청 → 정원 넘치면 대기 → 당일 코드 입력해서 출석 → 포인트/뱃지 쌓임**

---

## 3. 운영진이 보는 것

회원 화면에 더해, 별도의 **관리 화면(메뉴 16개)** 에 들어갈 수 있어요.

크게 다섯 묶음이에요:

- **메인** — 대시보드 (전체 현황 한눈에)
- **운영** — 회원 관리 · 스터디/프로젝트 · 이벤트 · 장소 · 출석
- **모집** — 지원서 심사 · 면접 일정 · 면접 질문 · 모집 설정
- **콘텐츠** — 공지 · 설문 · 문의 · 자료실
- **관리** — 포인트/뱃지 지급 · 예산

> 운영진 핵심 흐름: **지원서 접수 → 심사(심사중/합격/불합격) → 합격 시 결과 메일 자동 발송**

## 밑바탕 (참고만)

- 만든 것: **Next.js + Supabase**(로그인·데이터) + Tailwind(디자인)
- 로그인: **구글 계정**
- 알림: 이벤트/출석 관련은 **Slack**과 **이메일**로 자동 발송
- "둘러보기 모드"가 있어서, 로그인 안 해도 예시 데이터로 화면을 구경할 수 있어요

---

## 지금 상태를 한마디로

기능은 **아주 많이** 들어있어요. 동아리 운영에 필요할 법한 건 거의 다 있는 편이에요.
그래서 **"이 앱이 제일 잘하는 게 뭐지?"가 조금 흐려진 상태** — 이걸 어떻게 정리할지는 [redesign-for-designer.md](redesign-for-designer.md)에 담아뒀어요.
